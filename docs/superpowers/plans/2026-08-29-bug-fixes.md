# 蛋蛋世界 Bug 修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 一次性收口附件列出的盲盒、任务、蛋蛋币、组队、五维属性、大学吐槽榜、资料和管理员界面问题，并在全量验证后发布生产。

**Architecture:** 保留当前原生单文件前端与 Fastify/Prisma 后端。所有业务状态继续由 REST 接口写入和回读，WebSocket 只发送刷新事件；资金变化全部在 Prisma 事务中通过现有 `applyBuddyPointDelta` 记流水。管理员头像使用独立服务端设置记录，默认复用 `char-eggy-hermit.jpg`，普通用户永远不能选择或写入管理员头像。

**Tech Stack:** 原生 HTML/CSS/JS、Node.js、Fastify、TypeScript、Prisma 6、MySQL、Vitest、WebSocket。

## Global Constraints

- 保留现有认证、任务、盲盒、打听、反馈、排行榜和大学吐槽榜。
- 不启用短信/验证码发送；`VERIFICATION_PROVIDER=disabled` 保持不变。
- 商城保持前后端关闭，不运行商城迁移，不触碰“航线”或 Supabase。
- 仅移除“申请协商取消”前端入口，保留后端协商取消与历史数据兼容。
- 金币/任务状态修改必须事务化、幂等化并写入 `point_transactions`。
- 五维实时更新采用写后 REST 回读，跨页面由现有 WebSocket 事件触发回读，不新增轮询/SSE。
- 管理员头像默认 `char-eggy-hermit.jpg`；设置接口仅管理员可用，普通用户不可选。
- 完整测试、构建、隔离 E2E 通过后才合并 `main` 并部署生产；失败分支不得合并。
