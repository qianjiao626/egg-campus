# 我的任务卡片主题改版

## 目标

统一“我的任务”页面四个任务分类中的发布卡片与认领卡片，让用户可以通过颜色、状态和稳定的信息层级快速扫描任务，同时保留现有数据接口、筛选逻辑和点击事件。

## 范围

- 修改 `backend-handoff-package/growth-school.html` 的任务卡片 CSS 和两处卡片渲染 HTML。
- 覆盖拜师学艺（teach）、组队搭子（team）、蛋蛋求助（help）、奖励任务（reward）四类。
- 发布列表与认领列表使用相同的语义结构和视觉规则。
- 不修改 API、状态归一化、筛选器、弹窗、取消、提交、评价或认领业务逻辑。

## 视觉方向

卡片采用白色主体、圆角、轻阴影和顶部主题色带。结构固定为：

1. 状态标签与发布时间
2. 任务标题
3. 简介内容
4. 主题信息/奖励信息
5. 查看详情及原有操作按钮

主题色仅用于顶部色带、标题点缀、轻微背景渐变、主题信息标签和主要操作按钮：

| 类型 | 主题 | 主色 | 浅色底 |
| --- | --- | --- | --- |
| teach | 蓝紫 | `#5B5FEF` | `#F2F3FF` |
| team | 暖橙黄 | `#F08A24` | `#FFF6E8` |
| help | 青绿色 | `#0F9F92` | `#ECFBF7` |
| reward | 金棕黄 | `#B7791F` | `#FFF8E7` |

状态标签保持独立语义颜色：待审核橙色、已审核蓝色、已完成绿色、待修改红色、已取消灰色。

## 响应式与可访问性

- 桌面端卡片内容可伸缩，操作区靠右对齐。
- 900px 以下保持单列；标题和简介使用 `overflow-wrap:anywhere`，不产生横向溢出。
- 保留 `:focus-visible` 的可见焦点，不依赖悬停才能识别状态。
- 尊重现有 `prefers-reduced-motion` 规则，动画只使用短时的入场与悬停位移。

## 验收

- 四个分类的发布/认领卡片均使用新版结构和对应主题色。
- 顶部 Tab、状态筛选、查看详情、认领管理、确认完成、取消任务、提交完成、评价等现有点击事件仍存在。
- 任务标题、简介、时间、状态和操作按钮在桌面与移动宽度下均可读且不溢出。
- 现有前端契约测试与全量 Vitest 测试通过。
