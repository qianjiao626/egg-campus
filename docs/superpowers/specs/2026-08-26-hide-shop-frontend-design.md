# 商城前端暂时隐藏设计

## 目标

暂时关闭普通用户、商品发布者和管理员的全部商城前端入口及页面，同时完整保留商城页面代码、API 客户端、后端接口、数据库模型、迁移和测试，便于后期无缝恢复。

## 方案

- 在主页面根元素设置单一开关 `data-shop-enabled="false"`。
- 所有商城导航和商城页面使用统一标记 `data-shop-ui`，关闭时由 CSS 在首次绘制前隐藏。
- SPA 导航函数维护商城页面 ID 集合；关闭时任何内部商城导航都回退到当前角色首页，避免绕过隐藏入口。
- 发布者和管理员商城入口的权限计算继续保留，但只有开关开启时才能显示。
- 后期恢复只需把根元素开关改为 `true`，无需恢复被删除的代码。

## 不变范围

- 不修改 `api-client.js` 的商城方法。
- 不修改服务器商城路由、RBAC、Prisma Schema 或迁移。
- 不执行商城数据库迁移，也不部署商城后端。
- 不改动“航线”项目及其 Supabase 数据。

## 验收

- 源码仍包含全部七个商城页面和业务调用。
- 七个商城导航入口及七个页面均受统一标记控制。
- 开关默认关闭，直接导航到商城页面会回退。
- 非商城页面和登录流程保持原有行为。
