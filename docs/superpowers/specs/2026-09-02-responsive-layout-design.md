# 蛋蛋校园全端屏幕适配设计

## 目标

让主站 `growth-school.html` 与独立盲盒页在桌面、平板、手机上保持可读、可操作、无页面级横向溢出。业务逻辑、接口、事件处理和现有页面功能保持不变。

## 适配范围

- 主站：`backend-handoff-package/growth-school.html`
- 盲盒页：`backend-handoff-package/blind-box/index.html` 与 `backend-handoff-package/blind-box/styles.css`
- 只调整布局、尺寸、间距、溢出和触控表现；不重写业务 JS。

## 断点策略

| 视口 | 行为 |
| --- | --- |
| `> 1100px` | 保持桌面信息密度；侧栏固定宽度，主内容自适应剩余空间。 |
| `769-1100px` | 侧栏收窄；两列内容降为一列或双列；顶部操作区允许换行；表格提供局部横向滚动。 |
| `601-768px` | 平板竖屏/小平板模式；导航和工具栏换行，卡片以两列为主，弹窗宽度按视口收缩。 |
| `<= 600px` | 手机单列；侧栏变为紧凑图标导航，表单、任务卡、统计卡和弹窗全宽；按钮最小触控高度 44px。 |

断点只负责布局，不通过缩放整个页面来解决适配。字体使用现有字号体系，必要时用 `clamp()` 限制标题宽度，避免随视口连续缩放造成跳动。

## 主站布局

- 移除固定舞台对窄屏的依赖：桌面保留现有舞台尺寸表现，窄屏使用流式宽度和自然高度。
- `.app`、`.main`、`.page` 在窄屏允许纵向滚动，`min-width: 0` 贯穿 flex/grid 子项。
- 900px 以下：主内容单列，KPI、任务卡、设置面板按一列或两列重排；顶部栏和筛选工具自动换行。
- 768px 以下：表格容器启用局部 `overflow-x: auto`，单元格不撑破页面；详情/编辑弹窗使用 `width: min(100% - 24px, ...)` 和 `max-height: calc(100dvh - 24px)`。
- 600px 以下：侧栏压缩为图标导航，搜索框和次要操作折叠；任务详情、通知、反馈、个人资料等弹层改为底部抽屉或全宽卡片；安全区使用 `env(safe-area-inset-*)`。
- 所有主要按钮、导航项和表单控件保持至少 44px 高的触控区域；保留 `:focus-visible` 样式。

## 盲盒页布局

- 桌面保持“偏好工作台 + 盲盒舞台”双栏结构，舞台列使用 `minmax()` 防止被挤压。
- 平板切换为单列，舞台置于偏好设置之前，匹配卡片保持两列直到 600px。
- 手机全部单列；偏好选择、地区选择、特征卡片和消息操作纵向排列，长列表只在自身容器滚动。
- 所有弹窗和消息抽屉以视口为上限，使用 `100dvh`、安全区和可滚动内容区，不能遮住关闭/提交按钮。
- 装饰性舞台元素在手机缩放并限制在容器内，避免覆盖标题、指标和主操作。

## 溢出与状态规则

- 页面根节点禁止横向滚动；需要横向浏览的表格/选项条只在局部容器滚动。
- 长标题、学校名、用户名和任务描述使用换行或省略，不允许撑宽父容器。
- 弹窗打开时继续锁定背景滚动，关闭后恢复原状态。
- `prefers-reduced-motion: reduce` 下不新增动画，现有动画按页面规则降级。

## 验证

1. 静态检查：`git diff --check`，检查 CSS 选择器无窄屏互相覆盖。
2. 浏览器尺寸：`1440x900`、`1024x768`、`768x1024`、`390x844`、`360x800`。
3. 主站逐页检查：登录、任务广场、我的任务、吐槽墙、打听、个人中心、管理员看板、通知面板和所有详情/编辑弹窗。
4. 盲盒页检查：偏好设置、地区选择、匹配卡、消息抽屉、抽取弹窗、特征弹窗。
5. 验收条件：无页面级横向滚动；文字不溢出；按钮可点击且触控区域足够；桌面布局不回归；现有前端回归测试全绿。
