# 项目总览

## 目标

为蛋蛋校园建立可上线演进的用户认证和持久化数据层，并让盲盒交友的核心操作按照当前用户写入 CVM 上的 MariaDB。主站发布在 `https://dsxnb.com/dd/`；根域名现有“航线”站点保持原状。

## 当前架构

| 层 | 当前实现 | 事实来源 |
|---|---|---|
| 主站静态页面 | `backend-handoff-package/` | `growth-school.html` |
| API 服务 | Node.js + TypeScript + Fastify | `server/src/` |
| ORM 与迁移 | Prisma | `server/prisma/` |
| 数据库 | CVM 同机 MariaDB/MySQL，数据库名 `dandan_world` | `server/.env.example`、迁移文件 |
| 公开 API 前缀 | `/dd/api` | Nginx 配置和前端客户端 |
| 健康检查 | `/dd/health` | `server/src/app.ts` |
| 进程守护 | PM2，应用名 `dandan-world` | 生产运维记录 |
| 盲盒页面 | `/dd/blind-box/` 纯内容组件 | `blind-box/index.html`、`app.js` |

## 状态摘要

| 能力 | 当前状态 | 说明 |
|---|---|---|
| 注册、登录、退出 | 已上线并通过生产 smoke | 自主昵称+密码注册、refresh、`/users/me`、退出均验证 |
| 会话跨刷新恢复 | 已上线并通过生产 smoke | HttpOnly refresh cookie；公开 Cookie Path 为 `/dd/api`；浏览器不保存密码或 refresh token |
| 验证码 | Mock provider 可测 | 腾讯云 SMS 真实密钥、签名和模板尚未配置 |
| 主站盲盒嵌入 | 已完成 | 复用主站外壳，模块自身不再渲染外壳 |
| 盲盒基础数据 | 已接数据库 | 偏好、推荐、消息、好友申请等有独立 `buddy_*` 表 |
| 盲盒玩法记录 | 已有通用持久化接口 | `BuddyFeatureRecord` 记录 payload/result；声望结算等领域规则仍需补齐 |
| 线上备份恢复演练 | 待完成 | 脚本已存在，需在 CVM 会话恢复后执行 |

## 关键边界

- 浏览器只访问 HTTP API，不直连 MariaDB。
- 应用只使用 `dandan_world`，不读取、迁移或修改“航线”的 Supabase。
- refresh cookie 的公开 Path 是 `/dd/api`（上游 Fastify 使用 `/api`，Nginx 重写为 `/dd/api`），确保主站认证和盲盒接口共享会话。
- 管理员和普通用户都使用同一会话机制，权限由后端 `role` 校验，不由前端按钮决定。
