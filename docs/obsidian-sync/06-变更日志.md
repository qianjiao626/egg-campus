# 变更日志

## 2026-08-24

- 补充认证路由级回归：无邮箱/手机号时可直接使用昵称和自设密码注册，仍由服务端签发 HttpOnly refresh Cookie；联系方式注册继续强制验证码。
- 盲盒高级玩法 adapter 全量接入 `buddy_feature_records` 用户归属持久化接口，保留原 adapter 名称和会话刷新行为。
- 增加 `GET /api/buddy-box/features` 用户记录列表接口；盲盒刷新时恢复当前用户留言和已完成玩法状态，不再只依赖当前页面内存。

- 盲盒模式最终收口为纯内容组件：直接访问组件地址只输出盲盒业务内容，不再提供插件独立完整页面模式。
- 主站盲盒入口改用相对组件路径，避免本地预览与 `/dd` 子路径部署之间的路径差异；主站容器负责滚动。
- 本地最终验证：9 个测试文件、34 个测试通过，TypeScript 构建通过，盲盒脚本语法检查通过。
- 本轮只生成部署包，未宣称已完成 CVM 线上迁移或重启。
- 增加 `server/tests/auth-session-flow.test.ts`，覆盖注册事务、refresh Cookie 轮换、`/users/me`、logout 和旧会话失效；当前本地总计 10 个测试文件、35 个测试通过。
- 修复 Cookie Path：生产公开路径必须覆盖 `/dd/api`，否则盲盒 `/dd/api/buddy-box/*` 无法收到登录 Cookie；Nginx 已改为 `proxy_cookie_path /api /dd/api`。

- 盲盒插件完成纯内容化：删除插件顶部、侧边栏、页脚和独立标题；主站侧边栏直接在右侧容器加载 `/dd/blind-box/`。
- 盲盒保留 MBTI、资料、兴趣、今日想法、抽盒、推荐、消息、好友申请和玩法中心；主站容器负责滚动。
- 盲盒组件 CSS 清理历史外壳选择器，并取消玩法弹窗的独立滚动；生成 `output/releases/dandan-frontend-dd-20260824-content-component-final.zip`。
- 收紧 refresh Cookie 轮换测试，并生成待 MFA 后发布的精简后端包 `output/releases/dandan-server-deploy-20260824-mfa-ready-v2.zip`；包内不含 `.env`、`node_modules`、`dist` 或本地凭据文件。
- 认证代码已具备注册、登录、验证码、刷新、退出、找回密码和 `GET /api/users/me`。
- 会话使用 HttpOnly refresh cookie，access token 只在内存中；不持久化密码、refresh token 或验证码。
- 盲盒基础数据已接入 `buddy_preferences`、`buddy_boxes`、`buddy_messages`、`buddy_friend_requests`。
- 新增 `BuddyFeatureRecord` 迁移和 `/api/buddy-box/features` 通用读写路由，前端高级玩法 adapter 已接入该接口。
- 本地验证：后端 8 个测试文件、30 个测试通过；TypeScript 构建通过；盲盒两个脚本语法检查通过。
- 仍待完成：最新后端在线迁移/重启后的完整认证 smoke、浏览器跨刷新验证、真实腾讯云 SMS、备份恢复演练和高级玩法结算语义。
